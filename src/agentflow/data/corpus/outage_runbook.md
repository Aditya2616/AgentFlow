# Outage runbook

## Escalation
If an outage is not mitigated within 15 minutes, escalate to the engineering manager on call. After 60 minutes, notify the executive on call.

## First steps
Check the status dashboard, then the latest deploy. Roll back the latest deploy if the outage started within 30 minutes of it.

## After the incident
Write a blameless post-mortem within 5 working days.
